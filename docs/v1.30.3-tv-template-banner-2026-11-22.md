# v1.30.3 (2026-11-22) — TV banner adopts the Google TV template packaging

At Jonathan's order ("Adopt", 2026-11-22 00:15 EST), following the gap
analysis against the official Google TV Figma template (@tv, "TV App
Icon Template [Android TV & Google TV]", file AX4F41kCSaYnsft7spPHBO).

## Change (banner packaging only; art and code unchanged)

The v1.30.2 banner shipped as flat PNGs in `res/drawable` +
`res/drawable-xhdpi`. v1.30.3 restructures it to the template's
packaging, art identical ("Muse DA", Muse M + orange phone badge):

- Legacy ladder: `tv_banner.png` in drawable-mdpi (160x90),
  drawable-hdpi (240x135), drawable-xhdpi (320x180), drawable-xxhdpi
  (480x270), drawable-xxxhdpi (640x360); the unqualified drawable
  320x180 copy is kept as the default fallback.
- Adaptive set: `res/drawable-anydpi-v26/tv_banner.xml`
  (`<adaptive-icon>` with `@drawable/tv_banner_background`, solid
  #F0F2F5, and `@drawable/tv_banner_foreground`, logo + name on
  transparent; both layers in drawable-xxxhdpi). The app is minSdk 29,
  so the adaptive banner is the resolved banner on API 29+; flat PNGs
  remain for non-adaptive launchers.

Exports: `~/workspace/muse-app-logos/build_banners.py` now emits the
full set from the same composition (fg-over-bg verified to reproduce
the master exactly, 0 diff px).
