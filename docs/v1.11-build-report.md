## What shipped (corrected spec — Jonathan 2026-11-10 00:53–00:55 EST)
- ALL push channels KEPT (premise check refuted the design's
  duplication claim — see the errata appended to
  docs/direct-to-muse-app-design-2026-11-10.md; DA's channel is the
  only event-driven notification pipe).
- LOOP FIX at the source (GroundTruthListener.forwardPush): always-
  running notifications are ignored — FLAG_ONGOING_EVENT |
  FLAG_FOREGROUND_SERVICE from any package — plus a hard self-package
  exclusion. That class (incl. DA's own foreground-service
  notification) fed the ~4x/sec loop and both KV cap burns.
- TRANSPORT, data channels only (PushClient rework): tier 1 = local
  on-device hand-off into the in-prefs outbox (the delivery; cursors
  advance on it). Tier 2 = best-effort mirror POST, ONLY when the
  configured base is https://*.ts.net (Tailscale Serve form). The
  data channels never POST to a Worker/http base anymore.
  RESIDUAL GAP, stated plainly: the Muse app exposes no local ingest
  API, so the tier-1 outbox is where the path honestly ends today —
  data lands on-device in DA's store; no on-phone consumer reads it
  into the Muse app yet, and the fleet-side drain sees data-channel
  items only via a tier-2 mirror. Control lanes (report / commands /
  mode) are untouched and stay on WorkerClient's rendezvous.
- v1.10.0 voice/PiP code and the v1.5.2 reconciler carried over
  verbatim (files untouched — verified by mtime/diff scope: only
  build.sh, GroundTruthListener.java, PushClient.java changed).
- Phase 2 untouched and disarmed; pairing untouched; manifest
  untouched; no free-form shell.

## Tier status
Tier 2's https front is NOT up: `tailscale serve` on the box needs
sudo (serve config denied as the muse user); the sudo invocation was
refused by the safety policy in the parent session and not retried.
Unblock: an approved lane runs on the box:
  sudo tailscale serve --bg --https=8443 http://100.85.53.70:8792
giving base https://vps.taila56db5.ts.net:8443 (the existing :443
Serve/Funnel mount to 127.0.0.1:8952 must not be clobbered). The
Worker transport directive repoint (original Part B) stays held
until that front answers — pointing it at a dead base would strand
the phone. So the shipped path lands on TIER 1 (local) today, with
tier 2 code-complete and gated on that one box command.
